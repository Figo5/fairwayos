# FairwayOS development checkpoint — October 7, 2026

Active development is paused. This package contains 33 automatic annotated clips and both collections' compilations. The four standalone examples are curated for presentation, not a scored accuracy ranking. Individual MP4 bytes are unchanged.

Coverage is partial. Masters: ball 3781, head 869, body 3785, cup 2568 assertions in 9466 frames. PGA TOUR: ball 860, head 512, body 1477, cup 0 in 3814 frames. Counts are not accuracy. PGA TOUR lag-putt body tracking selects a caddie. One drive clip includes 20 frames of the next setup. Physical mph/carry/impact/tempo remain unverified. 142/131/111 mph values are source-reported broadcaster graphics, not FairwayOS measurements.

All jobs used zero manual tracking points. The optional cloud classifier used Claude Opus 5.5 on native image components; server configuration is disclosed in the repository. AI judgments and source-image review are not independent ground truth. Models, original downloads and private CLI/acquisition logs are excluded. JSON local paths are redacted; observation coordinates and timestamps are retained.

Resume with target-golfer identity and cup detection, independently labelled source-grouped evaluation, ball/head detection through camera cuts/insets, and honest measurement calibration. See the repository README and docs/resume-fairwayos.md.
