# Finish criteria

One command accepts a local PGA tee/approach clip and produces a playable annotated MP4 and analytics text. No website or coordinate export.

- Execute actual automatic body, ball and physical clubhead inference. No human clicks, fixed clip coordinates, imported archived predictions, or permanent unavailable implementation counted as complete.
- Hide each unsupported/lost target independently; no stale trail, guessed continuation, or shaft-as-head substitution.
- Parent reviews actual decoded pixels across consecutive frames, including missing-target intervals. Tests and candidate counts alone are not tracking verification.
- Run a second coherent shot before claiming cross-clip capability. Report bounded successes honestly.
- Analytics compute only supported observations. Ball speed/clubhead speed require valid physical calibration and real action-time; carry needs observable endpoints and appropriate geometry. No ground-plane projection of airborne ball. Missing evidence => unavailable; missing implementation is reported separately.
- Current analytics worker owns analytics.py and tests/test_analytics.py, adding evidence-based 2D joint angles; contract in /tmp/fairway-restart-analytics-contract.md. Claude integrates outputs. Image-space angles are not 3D biomechanics.
- No unsafe checkpoint loading, new global configuration, paid inference purchases, or media publishing. Cached MoveNet LiteRT is available without pickle. Model/resource paths must be configurable rather than legacy imports.
- Full tests, real inference, full output decode, and independent visual QA required. Maintain a small plain-function implementation; do not rebuild legacy framework.
