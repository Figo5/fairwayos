# All-clip clubhead research

The bounded Tiger 2019 Masters collection contains twelve local clips, five putts and seven full swings. `tools/tiger_clubhead_sam2.py` runs official SAM2.1 Hiera tiny forward from the existing operator clubhead point and a derived ±7 native-pixel box. A putt uses a native 225px crop; a swing uses a full-height rectangle of width 0.95 × height, clamped around the seed. Swing motion bounds scale with native height/720. Each record declares its actual policy. No correction, later reference coordinate or assisted path enters mask inference.

`seed_prompt.py` can derive one negative point on a nearby round white region from the seed image. Its shape/color gates are binary pixel measurements, not semantic ball identity or confidence. A negative inside the box is permitted: SAM2 concatenates box corner labels 2/3 with point labels 1/0; the box is not a promise that every interior pixel is foreground. Negative prompts can still harm segmentation or memory. Use `--negative-prompts` explicitly, and judge actual masks. Positive subpixel coordinates remain unchanged; raster lookup alone rounds/clamps them.

The model runner refuses existing evidence names, scopes frame/mask folders by output name, snapshots the code used, records prompt-patch origins, creates a mask receipt, and decodes frames sequentially. Partial runs declare which clips use SAM2 and which retain classic predictions. Existing experiment sources and model masks are preserved; the runner was polished after that neural run, so its newer extraction/provenance code has synthetic integration coverage, not another real neural run.

`tools/tiger_replay_clubhead_masks.py` measures all twelve head windows from checksum-verified masks using `adaptive_head.py`. Seed admission uses distance to actual compact-core pixels, rather than core centroid distance. Thickness is frozen from the original seed neighborhood so an unrelated thicker ball cannot set it. The point policy still requires two current-frame confirmations after loss, never backfills a gap, and stops at cuts. An ambiguous or round starting core is refused. This is mask geometry research, not a learned clubhead identity detector. Frame windows, seed placements, stroke types and cuts are operator/reference hints, not automatic scene discovery.

Reproduction is two-stage: run `tiger_clubhead_sam2.py` with a fresh output name to obtain masks and its mask receipt, then pass that receipt to `tiger_replay_clubhead_masks.py` for the refined points. Compose the selected route afterward with `tiger_stroke_family_route.py`. The model runner alone uses the earlier region policy and does not reproduce the refined score.

The 2026-10-01 result is 52 correct, 3 wrong, 37 missing out of 92 scored visible AI-reference clubhead samples, compared with 41/33/18 for the classic baseline. Putts improve to 32/0/22 from 20/33/1; full swings regress to 20/3/15 from 21/0/17. Dense hole 8 improves to 25/27 correct with zero wrong and zero markers on 14 labelled occluded frames; both observed recoveries take one frame and then remain correct for at least three consecutive labelled frames. Hole 18 putt and hole 13 tee fail initial shape admission. A two-pixel mask-support reconstruction arm was rejected because visible coverage fell to 37/92. The selected experimental route therefore uses the new mask policy on every putt and retains classic heads on every full swing: 53 correct, zero wrong, 39 missing /92; 70/0/39 on the expanded 109-sample references. `tools/tiger_stroke_family_route.py` selects from the declared operator stroke type alone and records each engine. This choice was made after inspecting development evidence; it is not a holdout win. No per-clip engine selection from later scores is used.

These are frozen AI visual references on already inspected footage, not human-confirmed truth or an unseen holdout. Sparse scores do not measure all-frame accuracy. Classic ball blocks are copied unchanged; existing television tracers are source graphics, not FairwayOS ball-flight reconstruction. Legacy comparison target options do not define SAM2 confidence thresholds; the recorded learned-mask profile is authoritative.

All twelve final showcase exports are separate **ASSISTED REVIEW · 2D IMAGE ESTIMATES** renders from the normal broadcast workflow. Their head coordinates are reviewed, reference-informed annotations; short joins are display interpolation. Those paths are never counted as automatic tracking success. Uncertain frames, long gaps and shot cuts split paths. Body landmarks are measured again with MoveNet; phase marks and golfer regions remain assisted. Side-on putts omit unstable shoulder/hip tilt cards. Image angles and pixel displacement are not calibrated physical swing measurements.

The next improvement is a stroke-aware head identity model and uncertainty handling for fast motion, followed by human-reviewed dense references and fresh footage. A review UI should expose the original seed, missed intervals and explicit operator corrections, and choose cards according to camera visibility. Do not promote this experiment into the default editor tracker.
